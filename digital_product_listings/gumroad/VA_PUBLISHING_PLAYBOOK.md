# 🚀 VA Publishing Playbook: GUMROAD

## 📋 Overview
This directory contains all **50 Digital Products** formatted specifically for publishing on **GUMROAD**.

### 📁 Directory Structure
- `images/`: Contains all 50 8K luxury cover images (`hair-salon.jpg`, `lawyer.jpg`, etc.).
- `LISTINGS_DATA.json`: Full metadata (titles, descriptions, tags, instant access URLs) for all 50 products.
- `LISTINGS_BULK_UPLOAD.csv`: Ready-to-import CSV spreadsheet for bulk upload tools.

---

## 📝 Step-by-Step VA Publishing Workflow

1. Open **GUMROAD** seller dashboard.
2. Select **"Create New Digital Product"** (or use bulk upload CSV).
3. Open `LISTINGS_DATA.json` and locate the target profession by slug.
4. Copy & Paste:
   - **Product Title**
   - **Price**
   - **Description & Value Stack**
   - **Tags / Keywords**
   - **Instant Access / Thank You Redirect Link**: `https://guidr-empire.pages.dev/product/[slug]`
5. Upload the cover image from `images/[slug].jpg`.
6. Set delivery file to redirect to the live digital guide or upload the PDF export.
7. Click **Publish**!
